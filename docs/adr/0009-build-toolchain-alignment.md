# ADR-0009: Согласованные инструменты сборки

- Статус: принято в рамках задачи ревью; поставка после проверок.
- Дата: 2026-10-03.
- План: [согласование инструментов](../plans/2026-10-03-toolchain-alignment.md).

## Контекст

Dependency PR обновляют Rust и Node Docker images без соответствующего
изменения CI. Новый образ Node не содержит вызываемый Corepack. Проверка
старым компилятором не доказывает готовность нового release image.

## Решение

Rust release CI и Docker используют 1.98.1; Node — 26.10.0. pnpm остаётся
10.28.1: Docker устанавливает точную версию напрямую через npm, CI — через
pnpm/action-setup. Проверка MSRV 1.88.0 выполняется отдельно. Base SHA и
locked/frozen dependency graph не меняются.

## Альтернативы

Сохранение предыдущих release toolchains потребовало бы снять обновления.
Установка отдельного Corepack добавила бы ещё один механизм и версию там,
где нужен только закреплённый pnpm.

## Последствия

Готовность обновления подтверждается compilation/tests и сборкой контейнеров
на новых версиях, а не наличием image tags. Бизнес-контракты, данные, runtime
pins и auth не меняются. Проверенные предыдущие commits/images дают откат.
