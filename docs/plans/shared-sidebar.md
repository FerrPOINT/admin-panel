# Стиль навигации из Base

Admin использует `SidebarItem` из `@sdlc/ui` для desktop и mobile навигации.
Оформление обычного пункта, hover, active и focus принадлежит Base.
Admin сохраняет состав меню, проверку маршрутов и закрытие mobile drawer.

Приёмка: тесты выбранного маршрута и drawer, проверка типов, общий frontend gate,
визуальное сравнение с Tracker и остальными продуктами в Codex IAB.
