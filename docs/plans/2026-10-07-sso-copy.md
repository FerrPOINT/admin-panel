# Единый вход и выход

План: заменить legacy подпись входа на «Войти через SSO», сохранить native
Central Auth и SDK pin. Выход завершает единую браузерную сессию; повторное
подтверждение same-origin перехода устраняется владельцем Central Auth в Base,
а не локальным обходом. HTML не кешируется между релизами; assets получают
immutable policy только при наличии файла. Missing bundle возвращает 404.

Проверки: login component tests, TypeScript, lint, readback exact frontend
image, реальный вход/выход на общем origin. Авторизация и данные не меняются.

Экран входа использует заголовок «Вход в платформу», без названия отдельного
продукта и fallback-бренда Base. Статическое предупреждение прежней миграции
Tracker не показывается анонимному пользователю как факт о его настройках.
