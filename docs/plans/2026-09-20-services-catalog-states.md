# Каталог сервисов: поиск, страницы и безопасные состояния форм

## Сценарии и данные

- Вошедший пользователь ищет сервис по названию, ключу или команде, фильтрует по состоянию и просматривает каталог по 20 записей. Источник данных остаётся `GET /api/v1/services`; фильтрация и пагинация выполняются в UI без изменения API.
- При ошибке загрузки список не показывает устаревшие строки React Query; повторный запрос доступен без потери фильтров. Пустой каталог и пустой результат поиска различаются.
- Любой вошедший пользователь может создать сервис или отправить новую декларацию. Пока запрос выполняется, поля, переключатели и закрытие формы недоступны. При ошибке черновик остаётся, ошибка видна рядом с действием; успешное сообщение появляется только после ответа API.
- Для UI-сервиса форма показывает `ui.render` и требует публичный URL. Новая декларация получает capabilities и URL активного контракта как исходный черновик, чтобы смена внутреннего API-адреса не удаляла сервис из переключателя и не подменяла веб-адрес внутренним.
- PATCH карточки и новой декларации выполняется одной транзакцией с одной проверкой `If-Match` и одним увеличением версии; ошибка не оставляет скрытую декларацию. Hash декларации включает публичный URL. Автором может быть только аутентифицированный субъект; legacy `requested_by` сохраняется в запросе, но чужое значение отклоняется.
- Исторические роли остаются в backend-контракте и аудите для совместимости, но не назначаются и не показываются в настройках UI.

## Проверки

- Unit: 25 записей дают страницы 20/5, изменение поиска или статуса возвращает на первую страницу; ошибка после успешной загрузки скрывает прежние строки и допускает retry.
- Unit: create/patch pending блокирует ввод и закрытие, ошибка сохраняет черновик, успех сбрасывает форму; защитная ветка без `canMutate` не показывает команды изменения.
- Unit: создание UI-сервиса передаёт `public_ui_url`; новая декларация действующего UI-сервиса сохраняет `ui.render` и публичный адрес при изменении базового URL.
- Backend: смена только публичного URL меняет hash; PostgreSQL-тест подтверждает атомарность PATCH, один version bump, повтор существующей декларации и rollback при ошибке/устаревшей версии; попытка подмены автора отклоняется.
- Mock Playwright: актуальный OIDC smoke и каталог на 320/375/768/1280 px в трёх темах, без overflow и с целями управления не меньше 40 px; ошибка после заполненного кеша, retry и черновик после ошибки создания.
- CI: lint, typecheck, unit и production build; после восстановления свободного места — live no-mock browser QA, keyboard и axe.
