# Подтверждение отзыва личного API-токена

## Подтверждённый дефект

При pending DELETE кнопка «Отмена» закрывает диалог, хотя запрос продолжает
отзыв токена в Central Auth. Воспроизведение использовало собственный PAT,
реальный API и блокировку его строки PostgreSQL; после закрытия ответ был 204,
а readback подтверждал `revoked_at`.

## Изменение и границы

Использовать существующий ConfirmDialog Base вместо локального подтверждения.
Admin сохраняет выбранный токен, русские подписи, mutation и отображение прав;
Central Auth сохраняет владение PAT, scopes и отзывом. Новых HTTP-контрактов,
env, migrations или общего API не требуется.

- Начальный focus — «Отмена», Tab остаётся в диалоге.
- Пока запрос выполняется, подтверждение, отмена и Escape заблокированы.
- Ошибка остаётся внутри текущего подтверждения; повторная попытка возможна.
- Отмена возвращает focus на исходную кнопку. После успеха focus возвращается
  на стабильную кнопку создания до обновления списка и удаления row action.
- Новое подтверждение очищает ошибку предыдущего запроса.

## Проверки

Регрессии pending/keyboard, ошибки следующего подтверждения и focus после
удаления action. Полные frontend/contract/packed-consumer/theme gates с pinned
Base и frozen locks. Production QA без API-моков: viewport/темы/keyboard/focus,
реальные SQL lock, 404, retry и PAT readback. Скриншоты содержат только metadata
собственных fixtures; секрет PAT не показывается. Backend/OpenAPI/Base pin
сверяются с исходным commit.

## Результат

Дополнительное ревью подтвердило overflow строки списка: допустимое имя PAT
из 100 символов без пробелов давало ширину страницы 887 px при viewport 375 px.
Диалог Base сохранял ширину 341 px. Исправление остаётся в продукте: название
обёрнуто в переносимый flex item, иконка не сжимается. API и максимальная
длина имени не меняются. Повторная QA-матрица использует максимальные имена
и проверяет геометрию страницы вместе с подтверждением.

87 frontend тестов и все релевантные гейты прошли; production QA — 16/16
сценариев без API-моков. См. [проверку и снимки](../screenshots/pat-confirmation-2026-10-04/README.md).

Повторная приёмка с максимальными именами: 87 frontend тестов и 17/17
production сценариев прошли. См. [геометрию и снимки](../screenshots/pat-label-2026-10-04/README.md).
