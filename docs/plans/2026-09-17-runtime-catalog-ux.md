# Актуализация runtime-каталога и общего UI

## Цель

Сделать Admin Panel источником полного каталога локальных сервисов и обеспечить
стабильный, диагностируемый контракт для общего переключателя приложений.

## Изменения

- Идемпотентно создавать отсутствующие записи каталога из
  `ADMINP_BOOTSTRAP_SERVICES`, не перезаписывая изменения администратора.
- Возвращать сервисы в стабильном продуктовом порядке без изменения схемы API.
- Показывать в Runtime Inspector UI URL, тип, health и явные состояния загрузки,
  ошибки и пустого каталога.
- Сохранить `ui_url = null` для API-only сервисов.

## Проверка

- Backend: fmt, clippy, unit и интеграционные тесты.
- Frontend: lint, typecheck, unit, build и Playwright smoke.
- Локальный compose: повторный запуск не создаёт дубликаты, каталог содержит
  шесть UI-сервисов и два API-only сервиса.
