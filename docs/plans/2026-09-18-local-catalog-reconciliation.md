# Локальная синхронизация каталога

Источник локальных адресов сервисов — `ADMINP_BOOTSTRAP_SERVICES` в Compose.
При запуске Admin Panel создаёт отсутствующие записи и обновляет только те,
чья активная declaration создана `local-bootstrap`. Если содержимое не
изменилось, новую версию не создаёт. Активные declarations администраторов
не затрагиваются. Изменение адреса сохраняется новой одобренной версией,
чтобы история оставалась доступной. Публичный runtime-контракт не меняется.

Проверки: чистый и повторный bootstrap, смена локального URL, ручная
declaration, health probe после обновления, фронтенд и backend CI.
